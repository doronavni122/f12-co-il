# F12 — חדשות פיננסים

Hebrew finance news site for **f12.co.il**.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS 4
- Static/ISR article pages, RSS, sitemap, JSON-LD
- RTL Hebrew UI (Heebo + Rubik)

## Develop

```bash
pnpm install
pnpm dev
```

Dev server: http://localhost:3002

## Build

```bash
pnpm build
pnpm start
```

## Env

Copy `.env.example` → `.env.local`. See also `.env.development.example`.
